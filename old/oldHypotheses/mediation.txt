\subsection{Mediation Analyses}

\textbf{Analytic strategy.} Simple mediation models were estimated using ordinary least squares with nonparametric bootstrap inference ($3{,}000$ resamples). For each model, path $a$ estimated the effect of predictor $X$ on mediator $M$, path $b$ estimated the effect of $M$ on outcome $Y$ controlling for $X$, path $c$ estimated the total effect of $X$ on $Y$, and path $c'$ estimated the direct effect of $X$ on $Y$ controlling for $M$. The indirect effect was computed as $ab$ and evaluated using a bootstrap $95\%$ confidence interval and bootstrap $p$-value.

\subsection{Mediation Results}

\subsubsection{Hypothesis 1}
For the condition-adjusted model ($n=1008$) with $X=\text{time}$, $M=\text{emotional trust}$, and $Y=\text{analytical trust}$, path $a=-2.337$ ($p<.001$), path $b=1.270$ ($p<.001$), total effect $c=-1.329$ ($p=.024$), and direct effect $c'=1.640$ ($p=.004$). The indirect effect was significant, $ab=-2.969$, $95\%\,CI[-3.600,-2.366]$, $p_{boot}<.001$, providing evidence consistent with mediation.

\subsubsection{Hypothesis 2}
In the Interactive-only model ($n=504$; $X=\text{time}$, $M=\text{emotional trust}$, $Y=\text{analytical trust}$), path $a=-2.262$ ($p<.001$), path $b=1.136$ ($p<.001$), $c=-1.421$ ($p=.074$), and $c'=1.148$ ($p=.141$). The indirect effect was significant, $ab=-2.569$, $95\%\,CI[-3.460,-1.786]$, $p_{boot}<.001$, providing evidence consistent with mediation.

In the Text-only model ($n=504$), path $a=-2.413$ ($p<.001$), path $b=1.394$ ($p<.001$), $c=-1.238$ ($p=.156$), and $c'=2.125$ ($p=.011$). The indirect effect was significant, $ab=-3.363$, $95\%\,CI[-4.287,-2.467]$, $p_{boot}<.001$, providing evidence consistent with mediation.

\subsection{Mediation Summary}
Statistically significant indirect effects were observed for Hypotheses 1 and 2. Hypotheses 3--5 were tested and found to be non-significant in mediation; those analyses are reported in the supplementary materials below.
