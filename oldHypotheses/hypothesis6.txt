\subsection{Hypothesis 6: Group x Condition Effects Across Trust Dimensions}

This analysis includes three subhypotheses visualized in a single three-panel figure (left/middle/right).
All trust-change outcomes are computed as per-item average change (Post - Pre).

\subsubsection{Hypothesis 6.1}
\textbf{Hypothesis.} There will be a difference in analytical pre-post trust scores by group and condition.

Paired t-tests (Pre vs Post) within each Group x Condition cell:
- WEIRD / Interactive: $t(59) = 2.17$, $p = .034$, $\Delta M = -0.180$.
- WEIRD / Static (Text): $t(59) = 2.14$, $p = .037$, $\Delta M = -0.123$.
- NORMAL / Interactive: $t(191) = 2.81$, $p = .006$, $\Delta M = -0.130$.
- NORMAL / Static (Text): $t(191) = 2.74$, $p = .007$, $\Delta M = -0.124$.
Omnibus ANOVA across the four Group x Condition cells: $F = 0.14$, $p = .938$.
Interaction effect (Condition x Group) on analytical change: $b = -0.050$, $t(500) = -0.39$, $p = .696$.
Graph mapping: left subplot shows analytical-change bars by Group and Condition; asterisk markers below the lower whiskers denote significant paired pre-post differences for those cells.
Decision: Supported.

\subsubsection{Hypothesis 6.2}
\textbf{Hypothesis.} There will be a difference in emotional pre-post trust scores by group and condition.

Paired t-tests (Pre vs Post) within each Group x Condition cell:
- WEIRD / Interactive: $t(59) = 1.71$, $p = .092$, $\Delta M = -0.104$.
- WEIRD / Static (Text): $t(59) = 1.22$, $p = .229$, $\Delta M = -0.081$.
- NORMAL / Interactive: $t(191) = 9.48$, $p < .001$, $\Delta M = -0.297$.
- NORMAL / Static (Text): $t(191) = 10.57$, $p < .001$, $\Delta M = -0.326$.
Omnibus ANOVA across the four Group x Condition cells: $F = 7.49$, $p < .001$.
Interaction effect (Condition x Group) on emotional change: $b = -0.051$, $t(500) = -0.55$, $p = .585$.
Graph mapping: middle subplot shows emotional-change bars by Group and Condition; asterisk markers below the lower whiskers denote significant paired pre-post differences for those cells, and a centered $ns$ marker below WEIRD bars indicates no significant WEIRD emotional pre-post change.
Decision: Supported.

\subsubsection{Hypothesis 6.3}
\textbf{Hypothesis.} There will be differences in analytical-vs-emotional trust difference between group and condition.

Welch t-tests (WEIRD vs NORMAL) within each condition:
- Interactive: $t = -2.28$, $p = .025$, $M_{WEIRD} = -0.076$, $M_{NORMAL} = 0.167$.
- Static (Text): $t = -2.46$, $p = .015$, $M_{WEIRD} = -0.042$, $M_{NORMAL} = 0.202$.
Omnibus ANOVA across the four Group x Condition cells: $F = 3.82$, $p = .010$.
Interaction effect (Condition x Group) on analytical-vs-emotional difference: $b = 0.001$, $t(500) = 0.01$, $p = .996$.
Graph mapping: right subplot shows analytical-vs-emotional difference bars by Group and Condition; colored asterisk markers below lower whiskers indicate significant WEIRD vs NORMAL contrasts within condition.
Decision: Supported.

\textbf{Asterisk key:} $*\;p<.05$, $**\;p<.01$, $***\;p<.001$.
